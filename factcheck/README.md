# Fact-check logs

One file per episode (`epNN-name.md`). Each lists the claim, a verdict, and what was changed in the script.

**Method and limits (read this):** claims were checked with web searches that returned summaries of Wikipedia, Britannica, encyclopedia entries, museum pages, university pages and study sites. I could not open or read books, inscriptions' critical editions or primary sources. So:
- "Verified" means a search summary agreed with the claim; it is *not* the same as checking the cited book.
- "NOT verified" means the search did not return the claim; it may still be right (many are standard dates). Check these in the sources named in the episode's `Metadata` block before recording.
- "FIXED" means the script was changed because the search contradicted it or showed the claim was disputed, uncertain, or legendary.
- Many search results were low-quality study sites. Where a single weak source supported a claim, the log says so.

A human reviewer (ideally someone with a history background) should still read each script against the cited books before voiceover.
