# Publishing Checklist

## One-time channel setup
- [ ] Channel name, handle, logo, banner (2560×1440 safe area), About text, contact email
- [ ] Verify the account with phone (needed for >15 min videos and custom thumbnails)
- [ ] Set defaults: category "Education", language English, tags, upload license (Standard)
- [ ] Create playlists: "Kings of India", "Mongols", "Russia", "Europe", "China"
- [ ] Channel trailer (60 s)

## Per video
- [ ] Title (≤60 chars, curiosity + keyword). e.g. "Ashoka: The King Who Gave Up War After Kalinga"
- [ ] Description: 2-line hook, chapter timestamps, sources, image credits, playlist link, disclaimer on AI voice/visuals
- [ ] Chapters (first at 0:00, ≥3, each ≥10 s)
- [ ] Tags 8–12 (+ 3 hashtags in description), main keyword in first line
- [ ] Custom thumbnail, captions (.srt), end screen (last 20 s), cards
- [ ] Altered/synthetic content disclosure answered honestly
- [ ] Not "made for kids"
- [ ] Schedule at audience peak (India: Sat/Sun 6–8 pm IST, or weekday 7 pm)
- [ ] Pin a comment: "Which king next?"

## After publishing
- [ ] 2 hours: reply to comments
- [ ] Post 2–3 Shorts, share on WhatsApp/Instagram/X communities
- [ ] 48 h: check CTR (target 4–8%), average view duration (target 35%+), retention dips → fix next script
- [ ] Add learnings to `docs/lessons.md`
