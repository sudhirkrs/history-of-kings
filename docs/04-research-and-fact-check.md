# Research & Fact-check (authenticity)

## Source ladder (highest first)
1. Primary: inscriptions, coins, contemporary chronicles (e.g. Ashoka's edicts, Ain-i-Akbari, Akbarnama, Chinese travellers).
2. Academic secondary: university-press books and journal papers (Romila Thapar, Upinder Singh, R.C. Majumdar, Satish Chandra, Burton Stein, Jadunath Sarkar, J.J. Saunders for Mongols, etc.).
3. Reputable reference: Encyclopaedia Britannica, Oxford/Cambridge histories, ASI / museum pages.
4. Wikipedia: only as a pointer to the above — never cite as final.
Avoid: viral social posts, unsourced YouTube videos, nationalist or revisionist pamphlets.

## Rules
- Every date, number, and quote needs 2 independent sources, or is flagged "traditionally said".
- Separate legend from evidence aloud in the script.
- Show both sides where historians disagree.
- Keep a `sources.md` in each episode folder (author, title, page).

## Fact-check checklist (tick before voiceover)
- [ ] All dates cross-checked
- [ ] Names/spellings consistent (choose one scheme, e.g. "Chandragupta", "Chanakya")
- [ ] Numbers (army, casualties) labelled as estimates and sourced
- [ ] Quotes verified word-for-word with source
- [ ] Maps match the period's real borders
- [ ] Images are period-appropriate (don't show a 19th-century painting as a "portrait")
- [ ] Sensitive topics reviewed for fairness
- [ ] Optional: send script to one history teacher/reader for review

AI tools (including this kit) can draft, but **a human must verify every fact against sources** before publishing.
