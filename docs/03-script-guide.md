# Script Guide

## Length maths
Narration ≈ 145 words/min. 20 min ≈ 2,900 words (the maximum). The current drafts run 1,200–2,000 words = 8–14 min, which is fine: never pad. Each script's header shows its measured length (tools/make_video.py parses it).

## Template (copy for every episode)
| Block | Time | Words | Job |
|---|---|---|---|
| Hook | 0:00–0:40 | 100 | Dramatic moment or question; promise the answer |
| Context | 0:40–3:00 | 330 | Where/when; political situation; map |
| Rise | 3:00–8:00 | 700 | Early life, how power was taken |
| Peak | 8:00–14:00 | 850 | Major wars/reforms; the defining decision |
| Fall | 14:00–17:00 | 420 | Decline, death, succession |
| Legacy | 17:00–19:00 | 280 | What survived; how we remember |
| Debate + CTA | 19:00–20:00 | 120 | What historians dispute; invite to next episode |

## Writing style
- Grade-8 English. Prefer "used" to "utilised". Explain every foreign/technical term once.
- Short sentences. Max one number or date per sentence; round big numbers.
- Always give approximate dates as BCE/CE and say "around" when uncertain.
- Signal certainty: "inscriptions show…", "later Buddhist texts claim…", "historians estimate…".
- Open loops ("But then something changed…") every 2–3 minutes for retention.
- No modern politics, no insults of communities, no unverified "greatest ever" claims.

## Script file format
Two columns per line: `NARRATION` and `[VISUAL: …]` cues, plus `[SOURCE: …]` tags to feed the fact-check.
